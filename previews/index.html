Four looks for one page.

Design previews for Carine to react to. Design 04 is new: a simpler, hand-painted take, following her feedback. The first three each follow a Webflow template. All four use the same words and the same portrait, so the only thing changing is the look. Best viewed on a laptop; each also works on a phone. For comparison, the current draft is here (opens in a new tab).

The same in all four

  • Rebecca’s v1 copy, word for word: the four planning areas, the three steps and the contact section.
  • One call to action, WhatsApp, with the floating button on every scroll position.
  • The regulatory details and the footer disclaimer, which is still placeholder wording until Financial Alliance compliance signs off.
  • No testimonials, client numbers or stock photos. Where a template relies on those, the slot holds a real detail or an honest “photo to come”.
